# file_words_reverser.cpp
This C++ program reads a text file, reverses the order of all words in it, and writes the result to a new output file. It preserves all words but prints them from last to first. The program also opens the resulting file automatically on Windows for quick viewing.

Features :

Reverses the order of words in any text file.

Handles files of any length.

Uses a vector to store words for easy manipulation.

Simple and lightweight C++ implementation.

Automatically opens the output file on Windows.

Usage :

Prepare a text file with words separated by spaces (e.g., text1.txt).

Compile the program:
g++ reverse_words.cpp -o reverse_words
